## Project position

Suggested category: **Best Use of Microsoft Foundry Project** (code-defined, evidence-selecting and commentary-writing Agent Framework agents running against a Foundry-hosted model). The implemented agent chain is not a Foundry Hosted Agent and is not a live match data ingest system. If entering a category focused on sophisticated multi-agent orchestration, describe this limited role separation accurately.

Strengths: explainable synthetic tactical events; body-relative alternatives; teammate coverage and simplified offside; synchronized 2D/3D match replay; evidence-grounded AI storytelling.

Current scope gaps relative to the *aspirational challenge brief*: no continuous live-event ingest, no full automated multi-event match recap, no dedicated fan/analyst UI switch; the underlying APIs can generate audience-specific narrative but Studio currently requests fan mode only. These are potential **scoring gaps**, not automatic proof of ineligibility.

## Suggested 95–110 second demo structure

- Problem and title (0–12 s): a defender's important positioning is often invisible.
- Choose a synthetic situation / defender and pre-pass options (12–36 s).
- Replay 3D + synchronized 2D; choose a new defender movement and show modelled outcome (36–67 s).
- Show Foundry EvidenceEditor → CommentaryWriter grounded narrative and fallback safeguard (67–89 s).
- Close with practical value, limits, and next steps (89–105 s).

Keep video footage and narration in English, avoid copyrighted music, and do not claim indices are xG probabilities.
